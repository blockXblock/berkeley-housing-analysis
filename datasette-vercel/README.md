# Berkeley Housing Pipeline - Datasette

Interactive database of 70 Berkeley housing projects (6,363 units).

🗺️ **Live Site:** https://berkeley-datasette.vercel.app

## Features
- Interactive OpenStreetMap with clustering
- SQL query interface
- Filter by year, project size, status
- Export data as CSV/JSON
- 70 mapped projects
- 6,363 housing units

## Data Source
City of Berkeley Planning Department

## Tech Stack
- Datasette (database UI)
- datasette-cluster-map (mapping)
- Vercel (hosting)
