To: City of Berkeley, Office of the City Clerk
Subject: CPRA Request — Residential Building Permits and Planning Records 2018-2022 (Follow-up to BP Annual Permit Report)

Dear City Clerk:

This is a follow-up to a previous CPRA request that produced "BP_Annual Permit Report.xlsx" covering residential building permits issued January 1, 2023 through December 31, 2025.

I request similar reports for the prior period: January 1, 2018 through December 31, 2022. Two datasets are requested.

---

PART 1: Building Permits 2018-2022

The same field set as the prior Building Permits report, covering January 1, 2018 through December 31, 2022. Specifically, all residential building permits issued during this five-year period, including but not limited to:

1. Permit number
2. Property address (street number, street name, street type)
3. APN (Assessor Parcel Number)
4. Permit type (new construction, addition, ADU, JADU, demolition)
5. Work description
6. Number of dwelling units (existing, proposed, added, removed)
7. Permit application date (submittal date)
8. Permit issued date (issuance date)
9. Final inspection date (if applicable)
10. Certificate of occupancy date / "finalized" date (Berkeley uses these terms equivalently; please include whichever field Accela maintains for permit completion)
11. Current permit status (issued, finaled, expired, cancelled)
12. Valuation amount (job valuation)
13. Applicant/contractor name
14. Total fees assessed

If possible, please include additionally:

15. Parent permit reference — if Accela tracks a parent or master permit ID for sub-permits (electrical, plumbing, mechanical, fire, signage permits associated with a primary building permit), please include that field. This would significantly reduce analytical noise from sub-permit proliferation.

16. Affordability/BMR designation per permit — if Accela tracks which units within a permit are designated Below Market Rate, deed-restricted, or designated for specific income levels (Extremely Low, Very Low, Low, Moderate), please include that information.

17. Residential demolition permits issued during the same period.

---

PART 2: Planning Records 2018-2022

In addition to the Building permits above, I request a similar report drawn from Accela\'s Planning module for the same period (January 1, 2018 through December 31, 2022). Specifically, residential or housing-related planning records, including but not limited to record types prefixed:

- ZP (Zoning Permit / Use Permit)
- AUP (Administrative Use Permit)
- UP (Use Permit)
- PLN (Planning case)
- LMSAP (Landmarks / SB330 preliminary applications)
- Design Review cases

The fields requested for Planning records are the same as items 1-14 above (record number, work location, APN where applicable, record type, project description, dates, status, valuation if recorded), insofar as they apply to planning records. I recognize some planning records may not have all the fields available for building permits — please include what is available.

The two datasets can be delivered as separate CSV or Excel files, ideally exported from the same Accela installation that produced the prior Building Permits report.

---

CONTEXT (for staff judgment on borderline records)

We are tracking Berkeley\'s housing pipeline from initial application through entitlement to building permit issuance to certificate of occupancy. The two datasets above, joinable by APN, would allow us to reconcile entitlement applications against building permits issued and identify projects in the entitlement pipeline that have not yet received construction permits. This supports independent analysis of the City\'s Annual Progress Reports (APRs) by Berkeley High School and UC Berkeley data science classes.

An initial working implementation may be seen at BerkeleyBuild.com

If any record types in the Planning module appear borderline for inclusion (e.g., a permit type that is housing-adjacent but unclear), please include them rather than exclude them — we can filter on my end.

## Background and rationale

The previous CPRA fulfilled April 20, 2026 covered 2023-2025 and was sufficient to identify recent permit activity but not historical context. Analysis of the v1 housing pipeline database revealed that 63% (112 of 179) of tracked projects had no CPRA matches — partly because many were entitled or permitted before 2023, the start of the prior CPRA window.

NotebookLM analysis of Berkeley\'s APR submissions identified 7 projects (686 units total) that appear in multiple years\' permit reports due to reissuances:
- 1598 University Ave (207 units): 2023 + 2024
- 3030 Telegraph Ave (144 units): 2023 + 2024
- 1701 San Pablo Ave (110 units): 2023 + 2025
- 2099 M L King Jr Way (72 units): 2022 + 2024
- 2527 San Pablo Ave (63 units): 2023 + 2024
- 1740 San Pablo Ave (54 units): 2023 + 2025
- 2403 San Pablo Ave (36 units): 2023 + 2025
  The 2025 APR counted the same project twice

The 2018-2022 historical data is essential for tracking reissue patterns, verifying when projects\' original permits were issued, and matching v1\'s older project records against ground truth.

The addition of Planning records to this request enables joining entitlement actions (planning) to construction actions (building) by APN, supporting full pipeline reconstruction from application through certificate of occupancy. This was added based on guidance that planning records and building records, when joined by parcel, give a more complete picture than building permits alone.
