Notebooks

StageNotebookDescription
A A1_data_sources_setup Connect to Berkeley Open Data API, handle WAF blocks
A A2_address_standardization Normalize addresses (FIFTH ↔ 5TH, Ave ↔ AV)
A A3_geocoding_pipeline Match to lat/lon using 563K address lookup
B B1_lifecycle_tracking Track permit stages: Zoning → Building → CO
B B2_status_classification Classify status into pipeline categories
B B3_progress_indicators Identify stalled projects (>180 days)
C C1_pipeline_analysis Projects by status, conversion rates
C C2_timeline_analysis Processing times, bottleneck identification
C C3_proposal_vs_reality RHNA tracking, "Making It Pencil" analysis
D D1_monthly_report_generator HTML/PDF/JSON report generation
D D2_dashboard_data_export SQLite + Datasette deployment
D D3_alerts_monitoring Status change alerts, milestone tracking
