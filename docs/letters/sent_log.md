# Letters sent

This file tracks correspondence sent on behalf of the project. Add entries chronologically.

Drafts are gitignored (`docs/letters/*.md` with negation for this file). When a letter is sent:
1. Save the as-sent version to `docs/letters/sent/YYYY-MM-DD_recipient.md` (this subdir is also gitignored unless decided otherwise)
2. Add a metadata entry below with date, recipient, subject, and any link to a published response
