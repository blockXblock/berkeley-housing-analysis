Query Berkeley's housing record directly — no records request required

Everything on this site derives from one database, rebuilt from primary sources (every permit 2015–2026, audited row-by-row against the state filing). That database is public. The links below open it in your browser — a full SQL workbench, no installation, no account — with the question already typed in. Edit anything and re-run.

Ground rules & citation

  • Cite as: "berkeleybuild.com, an independent reconstruction of Berkeley's housing records from city permit data" — and please link the page you used.
  • Every figure traces to a public record; the method and its audit live at the Audit page (our count vs the city's differs by 130 units of ~4,200, every row named).
  • Dates carry precision honestly: a few records only know their year (they appear as Jan-1). When something matters for publication, ask us and we'll pull the primary document.
  • "SQL query took too long"? The browser workbench caps queries at one second — on this 4 MB database that almost always means a missing JOIN condition (check your ON clauses, add a LIMIT). For genuinely heavy queries, run Datasette on your own machine with a higher limit: pip install datasette, download the database file below, then datasette berkeley.db --setting sql_time_limit_ms 3500. Or send us the query and we'll bake it into the database as an instant view.
  • The database updates when the record does (harvest + records requests); the file you query is the dated public mirror at /data/berkeley_housing_v2_public.db.
