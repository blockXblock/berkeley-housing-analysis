# Start Here: Berkeley Housing Data Science Course

Welcome to an open-source course for learning civic data science through housing analysis.

## Who Is This For?

- **Students** (high school, community college, university) learning data science
- **City staff** wanting to understand their housing data
- **Community members** interested in housing transparency
- **Researchers** studying housing policy

## What You'll Learn

By working through these notebooks, you'll learn to:
- Collect and clean civic data from multiple sources
- Track projects through the permit pipeline
- Analyze patterns and identify bottlenecks
- Generate reports for compliance and transparency
- Understand development economics

## Course Structure

The course is organized into **five series**, each building on the previous:

| Series | Directory | What You'll Learn |
|--------|-----------|-------------------|
| **A: Data Collection** | `01_collection/` | Getting and cleaning data |
| **B: Timeline Tracking** | `02_tracking/` | Following projects through the pipeline |
| **C: Analysis** | `03_analysis/` | Finding patterns and insights |
| **D: Reporting** | `04_reporting/` | Generating reports and dashboards |
| **F: Feasibility** | `05_feasibility/` | Understanding development economics |
