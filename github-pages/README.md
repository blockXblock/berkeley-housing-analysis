# Berkeley Housing Permit Pipeline

Interactive map showing 84 housing development projects in Berkeley, CA (2020-2025).

## Live Map
Visit: https://blockxblock.github.io/berkeley-housing-map/

## Statistics
- **84** projects mapped
- **5,283** total housing units
- **2020-2025** timeline

## Data Source
Berkeley Planning Department permits, geocoded using Alameda County GIS data.

## Features
- Clustered markers for better performance
- Color-coded by project size
- Popup details for each project
- Mobile-responsive design

## Embedding
To embed this map in your website:
```html
<iframe src="https://blockxblock.github.io/berkeley-housing-map/" 
        width="100%" height="900" frameborder="0">
</iframe>
```
