# Berkeley City Finance Curriculum

Teaching notebooks on reading a city's money from its own filed documents,
in the house discipline: **every figure is derived at run time** from a facts
file carrying provenance (document, page, URL) — nothing typed into a chart.

Each module is generated by a script in `scripts/finance_curriculum/`
(markdown-in-source, text-sandwich viz, integrity checks in-notebook).
Regenerate: `.venv/bin/python scripts/finance_curriculum/build_fin1.py`
