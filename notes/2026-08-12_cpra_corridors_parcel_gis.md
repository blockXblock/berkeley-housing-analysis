**Subject: Public Records Act request — Corridors Zoning Update parcel-level data + GIS (College, North Shattuck, Solano)**

Under the California Public Records Act (Gov. Code § 7920.000 et seq.), I request the following
electronic records concerning the **Corridors Zoning Update** (consultant: Raimi + Associates;
project areas: College Avenue [Dwight to Alcatraz], North Shattuck, and Solano Avenue):

1. The **parcel-level GIS data** underlying the Existing Conditions Report (March 5, 2025) and the
   Alternatives Report (August 15, 2025), as **native GIS files** (Esri geodatabase, shapefile, or
   GeoJSON) and/or spreadsheet (Excel/CSV), including for each parcel in the three project areas:
   - APN, address, lot area;
   - **existing zoning district**;
   - **existing number of dwelling units** and existing use/occupancy;
   - existing building floor area and/or stories, where the dataset records it;
   - any **historic-resource, rent-controlled, or UC-ownership status** flags used in the analysis.
2. The **parcel/opportunity-site coding** shown in the color-coded maps in the Alternatives Report
   and the corridor workshop presentations — i.e., the attribute(s) classifying parcels by
   development or housing-capacity potential under each alternative, as native GIS/spreadsheet data.
3. Any **capacity or yield model outputs** (per-parcel or per-site projected unit counts, FAR, or
   height under each alternative) prepared by the consultant.
4. The **6th Cycle Housing Element sites inventory** (2023–2031) as an electronic parcel/site-level
   file (Excel/CSV or GIS), including per-site APN/address, existing zoning, and projected unit
   capacity by income tier.
5. The City's **current zoning designations by parcel** for the three corridors as a GIS layer
   (if not already published as open data), and any **General Plan land-use designations** for the
   same parcels.

Please provide records in native electronic format per § 7922.570 (GIS in its native format where
maintained as such). If any portion is exempt, please cite the specific exemption and produce all
reasonably segregable non-exempt portions. I am happy to narrow scope in consultation if that speeds
a response — the highest-priority items are #1 (existing units + zoning per parcel) and #2 (the
opportunity-site coding).
