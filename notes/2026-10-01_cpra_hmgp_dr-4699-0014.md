# CPRA — FEMA project DR-4699-0014, closed unfunded on December 12, 2024

**Why:** OpenFEMA (Hazard Mitigation Assistance Projects v4, fetched 2026-10-01; `data/raw/hazards/openfema/`) lists
Berkeley's $5,000,000 Hazard Mitigation Grant Program application **DR-4699-0014** ("205.5: Structural
Retrofitting/Rehabilitating Private Structures – Seismic", program FY2023) as **Closed on 2024-12-12 with no federal share
obligated**: two days after the City's 2019 Local Hazard Mitigation Plan lapsed (2024-12-10). FEMA's data gives no
reason. A near-identical $5,000,000 application, **DR-4683-0087-R**, is still Pending. The Berkeley Snapshot report says
only that the cause is "not on the record"; these two requests would put it there. Send both; they hold different halves.

**Standing tactic:** name the artifact. Every item below cites a project number either agency already files under.
