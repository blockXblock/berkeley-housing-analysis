## 5. Diagnostic hypothesis (evidence-based)

**Hypothesis a:** Auto-redirect fired but the fix's signals didn't detect it at check time — specifically a **timing race** between `page.evaluate(form actions)` and Accela's ASP.NET UpdatePanel content swap.

Evidence:

1. **HTML at debug-save time HAS the signal.** The form action in the failed-run HTML contains `./CapDetail.aspx?...capID1=DUB23&capID2=00000&capID3=00EYO...` in exactly the format the fix's signal 2 regex matches.
2. **HTML fingerprint matches the known-recovered single-result case.** All distinguishing markers (InspectionList=30 vs 32; Workflow=3; absence of `dgvPermitList`) align with B2022-01278's fingerprint, which the fix DOES recover.
3. **Flakiness, not deterministic failure.** 3 of 4 runs of B2023-02303 succeeded. Same code, same permit, same Accela host, same network — but different outcomes. Deterministic permit-class problems (e.g., "Alteration permits are missing from Accela's index") would fail every time.
4. **The failed run was slower, not faster.** Failed: 10.4s. Succeeded: 7.5s, 8.4s, 20.2s (headed). "Too fast" doesn't explain it. "Slow network ⇒ slow UpdatePanel swap ⇒ check fires before signals arrive" does.
5. **Zero anti-detection markers.** Not Cloudflare, not a login wall, not bot detection. The page is genuinely the CapDetail page; it's just that the scraper checked too early.
6. **Both signals failed in lockstep.** If only `page.url` failed (not yet updated) but `form action` succeeded, the fix would recover. The failed run had neither — suggesting the page was in a transitional state where the ASP.NET form's action attribute hadn't yet been rewritten by the UpdatePanel callback. That window is small but real.

**This hypothesis also retroactively reframes the post-fix-batch5 result.** Of the 3 Alteration permits that didn't recover in the batch-of-5 run (B2023-02303, B2024-03884, B2023-04430), at least B2023-02303 is now confirmed-recoverable. The earlier interpretation ("Accela's CapHome search doesn't index Alteration permits") was a pattern-based conclusion that does not survive contact with evidence on this permit. The other two should be re-tested before that interpretation can be retired entirely, but the working hypothesis is now timing-race not category-block.
