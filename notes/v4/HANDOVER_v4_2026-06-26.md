(approved, careful version): a confident `new_unit` with blank/null UnitsAdded defaults to **1** IF the
description/flags say single-dwelling (SFR/ADU/duplex-or-smaller); but if it looks MULTIFAMILY

Implement in `build_jn_c_v2.py` (`net_units` function), regenerate, rerun JN-C.

## SETTLED CLASSIFIER VOCABULARY (do not re-derive — John approved each)
- Priority-order rules (first match wins): (1) -REV/-DEF → subsidiary; (2) Demolition → demolition;
  (3) Sign → non_housing; (4) movable/tiny-home → new_unit ONLY with permanence markers (wheels
  removed/permanent foundation) else ambiguous; (5) **ADU=Yes REQUIRES description corroboration**
  (ADU/conversion/legalization language) → new_unit, else ambiguous (the dirty-flag case); (6)
  New+housing-language → new_unit; (7) New+units>0+no-disqualifier → new_unit; (8) New unconfirmed →
  ambiguous; (9) Alteration+conversion/legalization language → ambiguous; (10) plain alteration →
  alteration (units floored 0); (11) blank/unmatched → ambiguous (generous).
- `net_units` is PROSE-BLIND (from UnitsAdded, never description) and master-only.
- **ADU reality (web-verified):** ADUs are added via garage/basement CONVERSION (Alteration work-type)
  or LEGALIZATION (AB 2533, near-zero construction) — so Work Type=New is a good CORROBORATOR but a BAD
  GATE (it misses conversions). Description gates; New supports. Movable/tiny homes count only with
  permanence markers (wheels removed, permanent foundation), else inconclusive. ADU=Yes corroboration =
  description (best) OR Work Type=New; OccType=R-3 is a tiebreaker; UnitsAdded is EXCLUDED as a
  corroborator (the Durant temp-power@83 lesson).
- **Completion rule = clean v4 rule:** a building completes in the year its master New permit's
  permit_finaled event fires. NO best-permit-pick fallback (that was v3's Rule-C, source of wrong-picks).
- **Size bands (Berkeley-real, web-verified):** 5 units = legal multifamily/density-bonus/affordability
  line (appears 3 independent places); 2-19 = Berkeley's explicit "middle housing" band; real large
  projects are 100+ (110/160/169/240 in the news). Bands: 1 / 2-4 / 5-19 / 20-99 / 100+.
